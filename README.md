# Task Manager (Full Stack)

Simple CRUD app: Spring Boot REST API + React frontend.

## Tech Stack
Java 17, Spring Boot, Spring Data JPA, H2 Database, React (Vite), Axios

## Features
- Add a task
- View all tasks
- Mark a task as completed
- Delete a task

## How to Run
Backend: run TaskManager1Application in taskmanager-1 (port 8080)
Frontend: cd task-frontend, npm install, npm run dev (port 5173)

## Note
Data is stored in an H2 in-memory database, so it resets when the backend restarts.
